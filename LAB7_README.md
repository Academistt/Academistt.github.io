## VS Code / GitHub Pages steps still to be done in your GitHub account
1. Install VS Code extensions **Live Server** and **Prettier - Code formatter**.
2. In VS Code choose **File > Open Folder** and open the folder containing `index.html`.
3. Right-click `index.html`, choose **Open with Live Server** and check the Home / About sections.
4. On GitHub create a **Public** repository exactly named `Academistt.github.io`.
5. Upload all the files and folders from this directory to the root of the repository. Do **not** upload the outer ZIP as one file.
6. In repository settings, under **Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)` if not already configured.
7. Verify `https://academistt.github.io/` in the browser.

## Short defense explanations (English)
- `<!DOCTYPE html>` declares the HTML5 document type.
- `<html lang="en">` sets the language to English.
- `<meta charset="UTF-8">` enables international characters, including Turkish letters.
- `<title>My CV</title>` sets the browser tab title.
- `meta name="author"` records the author, and `meta name="description"` describes the CV page.
- `<link rel="icon">` defines the icon shown in the browser tab.
- `id="hero"` is the Home section, while `id="about"` identifies the About section.
- `<h1>` is the main heading; `<p>` is a paragraph; `<img src="...">` displays an image.
- `assets/css/main.css` contains the original template design; `assets/css/custom.css` contains personalizations.
- GitHub Pages publishes the website from the repository. Live Server shows it locally while editing.
